# 009 · 孢子化撤离

## 为什么

孢子化是退出地图并保存成果的主方式；按当前能量 10%（最低 1）扣费，成功返回培养皿。

## 变更内容

- 地图内可执行孢子化撤离：耗 1 AP + max(1, ceil(能量*0.1)) 能量。
- 成功后结束地图会话，携带资源回到培养皿。
- 能量不足以支付最低 1 点时不可撤离。
- 本变更若不存在进化系统则不实现进化固化。

**可验证标准：** 能量足够时撤离返回培养皿且能量按公式减少；无法支付时不可撤离。

## 功能 (Capabilities)

### 新增功能
- `spore-evacuate`: 孢子化撤离

### 修改功能
- （无）

## 影响

- 主要改动 `app/` 前端状态与对应场景 UI。
- 依赖地图会话、物种能量与行动点。
- 不修改 `游戏设定/` 文档正文；规则以已确认设定为准。
