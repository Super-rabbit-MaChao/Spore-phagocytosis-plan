- id: 02
- status: done
- depends: [01]

## Intent

补齐拒绝路径：行动点不足或无法支付最低能量消耗时禁止撤离，并给出简短可见提示。不改变切片 01 的成功撤离规则，也不结束地图会话。

## Verify

约 30 秒内手动确认：

1. 调试「能量清零」后点孢子化撤离 → 仍留在地图，提示能量不足
2. AP 扣至 0 后点孢子化撤离 → 仍留在地图，提示行动点不足
3. 恢复足够 AP/能量后仍可撤离回培养皿（回归切片 01）

## Steps

- [x] 撤离失败区分原因（缺 AP / 缺能量）
- [x] 地图 UI 展示简短失败提示（可复用翻格/移动/采集提示样式，自动消失）
- [x] 失败时不扣资源、不销毁会话、不跳转
- [x] 按 Verify 走一遍

- 本切片不实现族群归零/核心死亡等失败态拦截（后续变更）
- 验证：lint/build 通过。规则：能量 0 → `no-energy`；AP=0 → `no-ap`；足够时仍可撤离。请本地能量清零 / AP=0 后点撤离看提示。
