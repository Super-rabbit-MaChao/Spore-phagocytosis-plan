# 007 · 核心菌落移动

## 为什么

核心菌落移动到已揭示邻格是探索与采集前提。

## 变更内容

- 核心菌落可移动到相邻已揭示格。
- 消耗 1 行动点与按难度计算的能量。
- 移动后位置更新并在地图上可见。
- 禁止移入未揭示格。

**可验证标准：** 点选相邻已揭示格后核心位置改变并扣 AP/能量；不可移入未知格。

## 功能 (Capabilities)

### 新增功能
- `colony-move`: 核心菌落移动

### 修改功能
- （无）

## 影响

- 主要改动 `app/` 前端状态与对应场景 UI。
- 依赖 hex-map-session、turn-action-points、species-runtime-state。
- 不修改 `游戏设定/` 文档正文；规则以已确认设定为准。
