# 非法移动拒绝并提示

- id: 02
- status: done
- depends: [01]
- maps-to-task: [3.2]

## Intent

补齐拒绝路径：未揭示格、非邻接、行动点不足或能量不足时禁止移动，并给出简短可见提示。不改变成功移动规则。

## Verify

约 30 秒内手动确认：

1. 点击迷雾格（即使邻接）→ 不移动（若已有翻格则可能翻格；移动本身不发生）；或点非邻接已揭示格 → 拒绝移动并提示
2. AP 扣至 0 后再点合法已揭示邻格 → 拒绝并提示
3. 能量不足时（调试能量清零或调到不足 2）点合法格 → 拒绝并提示
4. 合法且资源足够时仍可移动（回归切片 01）

## Steps

- [x] 移动失败区分原因（未揭示/非邻接/缺 AP/缺能量）
- [x] 地图 UI 展示简短失败提示（可复用翻格提示样式，自动消失）
- [x] 与翻格点击共存：点迷雾走翻格逻辑，点已揭示走移动逻辑（或明确互斥文案）
- [x] 按 Verify 走一遍

## Notes

- 点击分发：迷雾 → flip；已揭示邻格 → move；其它 → 对应拒绝提示
- 可复用现有「能量清零」「消耗 1 AP」调试验收资源不足
- 验证：lint/build 通过。请点远处已揭示格 / AP=0 / 能量清零后验提示。
