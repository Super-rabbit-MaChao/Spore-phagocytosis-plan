# 008 · 采集资源且局内不再生

## 为什么

设定要求采集获取资源，且局内采后不再生。

## 变更内容

- 对当前核心所在资源格执行采集，获得能量/水分/营养等。
- 消耗 1 行动点与少量能量。
- 采空后该格本局变为空，不再刷新。
- 不实现占领格持续产出。

**可验证标准：** 在资源格采集后角色资源增加且格子变空；再次采集无收益。

## 功能 (Capabilities)

### 新增功能
- `resource-collect`: 采集资源且局内不再生

### 修改功能
- （无）

## 影响

- 主要改动 `app/` 前端状态与对应场景 UI。
- 依赖 hex-map-session、turn-action-points、species-runtime-state；通常还需 colony-move。
- 不修改 `游戏设定/` 文档正文；规则以已确认设定为准。
