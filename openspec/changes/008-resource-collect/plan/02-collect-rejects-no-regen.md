# 非法采集拒绝且采空不再生

- id: 02
- status: done
- depends: [01]
- maps-to-task: [1.2, 3.2]

## Intent

补齐拒绝路径与局内不再生：空格、行动点不足或能量不足时禁止采集并给出简短可见提示。资源格采空后，结束回合推进，该格仍保持为空、不可再采，禁止自动刷新。不改变切片 01 的成功采集规则。

## Verify

约 30 秒内手动确认：

1. 核心在空格上点采集 → 拒绝并提示；合法资源格仍可采集（回归切片 01）
2. 采空后同一格再采 → 拒绝或无收益，资源点不回来；结束回合后该格仍空，再采仍失败
3. AP 扣至 0 后再采合法资源格 → 拒绝并提示
4. 能量不足时（调试能量清零）再采 → 拒绝并提示

## Steps

- [x] 采集失败区分原因（空格/非资源、缺 AP、缺能量）
- [x] 地图 UI 展示简短失败提示（可复用翻格/移动提示样式，自动消失）
- [x] 采空后会话内该格保持 `empty`；结束回合不得把资源写回该格
- [x] 按 Verify 走一遍

## Notes

- 规格场景「采空不再生」必须经过回合推进；不要只在同回合再点一次就算验完
- 可复用现有「能量清零」「消耗 1 AP」调试验收资源不足
- 本切片不实现占领格持续产出或跨局再生
- 验证：lint/build 通过。规则：空格/再采/结束回合后仍为 `not-resource`；AP=0 → `no-ap`；能量 0 → `no-energy`。请本地采空 → 结束回合 → 点仍不在；再验空格/AP=0/能量清零提示。
