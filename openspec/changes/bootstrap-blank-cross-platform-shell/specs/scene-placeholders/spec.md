## 新增需求

### 需求:提供与设定对齐的空场景

系统必须提供至少以下空场景占位，并与《孢子进化》设定中的培养皿 / 地图循环方向：主菜单、培养皿、地图。各场景必须可显示占位说明，禁止实现玩法逻辑。

#### 场景:主菜单可进入
- **当** 用户打开主菜单场景
- **那么** 系统必须显示游戏标题级入口，并提供进入培养皿（或下一场景）的操作

#### 场景:培养皿为占位
- **当** 用户进入培养皿场景
- **那么** 系统必须显示培养皿占位内容，禁止执行真实时间恢复、投喂、出征结算等逻辑

#### 场景:地图为占位
- **当** 用户进入地图场景
- **那么** 系统必须显示地图主视区占位（例如空白棋盘/视口框），禁止实现翻格、移动、蔓延、回合结算等逻辑

### 需求:场景可切换

系统必须支持在已提供的空场景之间切换，切换后壳层必须反映当前场景名称或等效标识。

#### 场景:从培养皿进入地图占位
- **当** 用户在培养皿场景触发进入地图的操作
- **那么** 系统必须切换到地图占位场景，且不创建任何游戏存档或对局状态机

#### 场景:返回培养皿或主菜单
- **当** 用户在地图或培养皿场景触发返回操作
- **那么** 系统必须回到对应空场景，且禁止保留本阶段玩法进度（因本阶段无玩法进度）
