## 新增需求

### 需求:应用可本地启动

系统必须提供可通过包管理器安装依赖并以开发模式启动的空白前端应用；启动后根页面必须可在浏览器中打开。

#### 场景:开发服务器启动成功
- **当** 开发者在应用目录执行依赖安装与开发启动命令
- **那么** 本地开发服务器必须成功监听，并可通过浏览器访问根地址

#### 场景:根页面可渲染
- **当** 用户打开应用根 URL
- **那么** 系统必须渲染空白壳的主菜单或等效入口页面，且页面禁止依赖任何游戏玩法逻辑才能显示

### 需求:工程包含后续系统挂载点

系统必须在工程中预留用于后续玩法系统的目录或模块挂载点，并在本变更中保持为空（或仅含说明文件）。

#### 场景:系统目录存在且无玩法实现
- **当** 检查工程中的系统挂载目录
- **那么** 该目录必须存在，且禁止包含回合、资源结算、进化、孢子化等玩法实现代码
