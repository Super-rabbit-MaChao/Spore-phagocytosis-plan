## 新增需求

### 需求:同一应用支持网页与手机访问

系统必须通过同一 Web 应用入口支持桌面浏览器与手机浏览器访问，并正确配置移动端视口，禁止为手机单独维护第二套无法共用的入口工程（本阶段）。

#### 场景:桌面浏览器打开
- **当** 用户在桌面浏览器打开应用 URL
- **那么** 系统必须显示完整壳层布局且主内容可读

#### 场景:手机浏览器打开
- **当** 用户在手机浏览器打开同一应用 URL
- **那么** 系统必须按窄屏布局展示，禁止出现需横向拖拽才能看到主操作的不可用布局

### 需求:壳层 UI 分区清晰

系统必须使用统一壳层，将界面划分为顶栏、主视区、底栏（或等效三区），并禁止在首屏堆叠多组统计卡片、多入口仪表盘式控件。

#### 场景:三区结构可见
- **当** 用户进入任意已实现场景页
- **那么** 页面必须同时呈现顶栏区域、主视区与主操作区域，且主操作数量保持精简

#### 场景:主视区唯一主内容
- **当** 用户查看场景页
- **那么** 主视觉内容必须集中在主视区内，禁止在顶栏或底栏放入大块玩法信息面板
