# 005 · 回合行动点

## 为什么

设定每回合 3 行动点、每动作 1 点。需要先有可验证的回合壳，后续翻格与移动才能扣点。

## 变更内容

- 地图会话内维护当前回合行动点，初始 3。
- 提供结束回合将行动点重置为 3。
- UI 显示剩余行动点。
- 提供可复用的扣点接口；完整环境结算表不在本变更。

**可验证标准：** 地图内可见 AP=3；扣点后减少；结束回合后回到 3。

## 功能 (Capabilities)

### 新增功能
- `turn-action-points`: 回合行动点

### 修改功能
- （无）

## 影响

- 主要改动 `app/` 前端状态与对应场景 UI。
- 依赖 hex-map-session。
- 不修改 `游戏设定/` 文档正文；规则以已确认设定为准。
