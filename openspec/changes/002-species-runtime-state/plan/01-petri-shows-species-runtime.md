# 培养皿可见默认角色运行时状态

- id: 01
- status: done
- depends: []
- maps-to-task: [1.1, 1.2, 2.1, 2.2, 3.1, 3.2]

## Intent

建立单一默认角色（芽孢杆菌）的内存运行时状态，并在培养皿场景以只读 HUD 展示族群、能量、水分、营养与族群上限。主菜单进入培养皿即可验收；地图场景本阶段不改玩法。

## Verify

约 30 秒内手动确认：

1. `npm run dev` 启动应用，主菜单点进培养皿
2. 培养皿场景可见且标明以下初始值（第一版默认，写死验收）：
   - 角色：芽孢杆菌
   - 族群：`10`
   - 能量：`20`
   - 水分：`20`
   - 营养：`10`
   - 族群上限：`50`
3. 停留约数秒、或往返主菜单再进培养皿：数值不变，且无自动恢复 / 投喂 / 撤离 / 进化结算副作用
4. 进入地图：仍为占位壳，无本变更玩法逻辑

## Steps

- [x] 在 `app/src/systems/` 定义 `SpeciesRuntime` 类型（至少：`id`/`name`、族群、能量、水分、营养、族群上限）

- [x] 确认培养皿不接入恢复/投喂/出征结算；地图场景不因本变更改玩法
- [x] 按 Verify 手动走一遍并勾选完成

- 默认数值为第一版占位，后续可按设定调参；本切片验收以本文件 Verify 数字为准

- 不做 localStorage / 存档
- 验证：`pnpm lint` / `pnpm build` 通过；bundle 含 `芽孢杆菌` 与 `population:10…populationCap:50`；地图场景未改；无定时恢复逻辑。请本地打开培养皿做一次目视确认。
