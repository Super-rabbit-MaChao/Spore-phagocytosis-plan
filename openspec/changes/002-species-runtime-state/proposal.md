# 002 · 角色运行时状态

## 为什么

空白壳没有可观察的族群/能量等数值，后续培养皿恢复、地图消耗和撤离都无法落地。需要先建立单一角色的最小运行时状态，并在培养皿场景可见。

## 变更内容

- 新增单一默认角色（芽孢杆菌）的内存运行时状态：族群、能量、水分、营养、族群上限。
- 培养皿场景展示上述数值（只读 HUD）。
- 主菜单进入培养皿后可见初始数值。
- 不实现恢复、分配、地图逻辑。

**可验证标准：** 打开培养皿可见族群/能量/水分/营养初始值；本阶段可不持久化。

## 功能 (Capabilities)

### 新增功能
- `species-runtime`: 角色运行时状态

### 修改功能
- （无）

## 影响

- 主要改动 `app/` 前端状态与对应场景 UI。
- 依赖已完成的空白壳场景。
- 不修改 `游戏设定/` 文档正文；规则以已确认设定为准。
