# 投喂立即增加族群

- id: 01
- status: done
- depends: []

## Intent

把角色运行时状态改为可更新，并在培养皿提供无配方「投喂」：消耗营养立即增加族群。场景只触发动作，规则放在 `systems/`。

## Verify

约 30 秒内手动确认（默认开局：族群 10、营养 10）：

1. 进入培养皿，点击投喂一次 → 族群 `11`、营养 `5`
2. 再点一次 → 族群 `12`、营养 `0`
3. 营养不足时再点 → 族群与营养均不变
4. 无自动恢复、无配方选择 UI
