## 新增需求

### 需求:真实时间恢复族群
系统必须在培养皿按真实时间恢复当前角色族群数量，且不得超过该角色族群上限。

#### 场景:未满时恢复
- **当** 角色族群低于上限且经过既定真实时间间隔
- **那么** 系统必须增加至少 1 点族群且不超过上限

#### 场景:满员停止
- **当** 角色族群已达上限
- **那么** 系统禁止继续因自动恢复而增加族群

### 需求:支持无配方投喂
系统必须允许消耗该角色已持有营养直接增加族群，且禁止要求配方组合。

#### 场景:投喂成功
- **当** 玩家选择投喂且营养足够
- **那么** 系统必须扣除营养并增加族群
