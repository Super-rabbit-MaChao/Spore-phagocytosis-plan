# 非法翻格拒绝并提示

- id: 02
- status: done
- depends: [01]
- maps-to-task: [2.2, 3.2]

## Intent

补齐拒绝路径：非邻接、已揭示、行动点不足或能量不足时禁止翻格，并给出简短可见提示。不改变成功翻格规则。

## Verify

约 30 秒内手动确认：

1. 点击已揭示格或非核心邻接的迷雾格 → 不揭示、不扣资源，出现简短提示
2. 将 AP 扣至 0（结束回合前用调试消耗或多次翻格）后再点合法迷雾 → 拒绝并提示
3. 能量不足时（可用调试把能量调到 0）点合法迷雾 → 拒绝并提示
4. 合法且资源足够时仍可翻格（回归切片 01）

## Steps

- [x] 翻格失败区分原因（非邻接/已揭示/缺 AP/缺能量）

- [x] 可选：高亮当前可翻的邻接迷雾，降低误点（非必须）
- [x] 按 Verify 走一遍
