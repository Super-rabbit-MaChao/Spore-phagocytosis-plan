# 006 · 翻开相邻未知格

## 为什么

翻格是探索核心动作。需要在已有地图与行动点上实现可验证的翻格。

## 变更内容

- 玩家可翻开与核心菌落相邻的一个未知六边形格。
- 每次翻格消耗 1 行动点，并按难度扣除少量能量（土壤难度 1.0 时能量 1）。
- 翻开后显示格子内容（空或资源等简化类型）。
- 不实现移动与采集。

**可验证标准：** 翻开邻接迷雾格后变为已揭示并扣 AP/能量；非邻接或资源不足时不可翻。

## 功能 (Capabilities)

### 新增功能
- `tile-flip`: 翻开相邻未知格

### 修改功能
- （无）

## 影响

- 主要改动 `app/` 前端状态与对应场景 UI。
- 依赖 hex-map-session、turn-action-points、species-runtime-state。
- 不修改 `游戏设定/` 文档正文；规则以已确认设定为准。
