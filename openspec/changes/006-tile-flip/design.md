## 上下文

空白壳已具备主菜单 / 培养皿 / 地图路由。本变更只实现「翻开相邻未知格」这一可验证功能切片。

依赖 hex-map-session、turn-action-points、species-runtime-state。

## 目标 / 非目标

**目标：**
- 交付可在本地手动验证的 翻开相邻未知格。
- 保持 UI 三区壳层，不引入杂乱面板。

**非目标：**
- 不顺带实现其他玩法模块。
- 不做持久化存档（默认内存态）。
- 不引入后端服务。

## 决策

- 继续使用现有 Vite + React + TypeScript 应用内实现。
- 状态放在 `app/src/systems/` 对应模块，场景只负责展示与触发。
- 数值与规则对齐《游戏设定》已确认条目；本切片以外的系数可写死第一版默认。

## 风险 / 权衡

- [与后续模块接口不稳] → 缓解：导出明确函数与类型，避免场景内写死规则。
- [验收依赖真实等待过久] → 缓解：允许调试快进或缩短间隔（仅开发可见）。

## 开放问题

- 无阻塞本切片的开放问题；若实现中发现依赖缺失，先补依赖变更再继续。
