# 004 · 六边形地图会话生成

## 为什么

设定要求每次进入地图重新生成六边形布局，开局揭示核心格及 6 邻格。当前地图仅为占位，需要可观察的地图会话。

## 变更内容

- 从培养皿进入地图时创建新会话并重新生成六边形格子。
- 随机落入安全格，揭示当前格与 6 个相邻格。
- 格子至少区分未知与已揭示；已揭示可含空或资源标记（可简化）。
- 离开后下次进入再生成；本变更不实现翻格操作与回合。

**可验证标准：** 每次进入地图都得到新布局；开局可见核心周围已揭示，外围为迷雾。

## 功能 (Capabilities)

### 新增功能
- `hex-map-session`: 六边形地图会话生成

### 修改功能
- （无）

## 影响

- 主要改动 `app/` 前端状态与对应场景 UI。
- 依赖空白壳地图路由；建议在 species-runtime-state 之后。
- 不修改 `游戏设定/` 文档正文；规则以已确认设定为准。
