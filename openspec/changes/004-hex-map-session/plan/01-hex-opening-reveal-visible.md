# 开局可见核心与邻格揭示

- id: 01
- status: done
- depends: []
- maps-to-task: [1.1, 1.2, 2.1, 2.2]

## Intent

实现小型六边形地图生成：随机落入安全格，自动揭示核心格及其最多 6 个相邻格。在地图主视区渲染六边形格，区分迷雾 / 已揭示，并标出核心菌落所在格。场景只展示，生成规则放在 `systems/`。

## Verify

约 30 秒内手动确认：

1. 从培养皿进入地图，主视区出现六边形格子（不再是纯占位草图）
2. 可见核心菌落标记所在格；该格及其相邻格为已揭示
3. 更远处格子为未揭示（迷雾），与已揭示外观可区分
4. 无翻格、移动、回合操作

## Steps

- [x] 在 `systems/` 实现固定尺寸六边形地图生成（轴向坐标即可）
- [x] 随机选择安全落点；揭示核心格 + 存在的邻格（最多 6）
- [x] 格子状态至少含：未揭示 / 已揭示；已揭示可简化为空或资源标记
- [x] 地图场景渲染六边形格、迷雾/已揭示差异，并显示核心所在格
- [x] 按 Verify 走一遍

## Notes

- 第一版尺寸写死（建议半径 2～3 的六边形区域，保证外围有迷雾可看）
- 资源/危险类型可极简，后续变更再细化
- 验证：`pnpm lint` / `pnpm build` 通过；半径 3 共 37 格，中心开局揭示 7、迷雾 30。请 `pnpm dev` 培养皿→地图目视确认。
