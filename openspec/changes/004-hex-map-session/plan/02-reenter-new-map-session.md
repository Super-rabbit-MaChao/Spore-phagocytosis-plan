# 再次进入生成新地图会话

- id: 02
- status: done
- depends: [01]
- maps-to-task: [3.1, 3.2]

## Intent

把地图生成为「会话」：每次从培养皿进入地图创建新会话并重新生成布局，禁止复用上一局格子。离开地图后下次进入再生成。便于用可见的会话种子或布局差异验收。

## Verify

约 30 秒内手动确认：

1. 进入地图，记下调试可见的会话种子（或核心落点坐标 / 已揭示图案）
2. 返回培养皿，再进入地图
3. 新局种子或布局与上一局不同（连续两次即可）
4. 仍保持开局核心+邻格揭示、外围迷雾；无翻格/回合逻辑

## Steps

- [x] 提供地图会话模型（含种子或等价可观察标识），进入 `/map` 时创建新会话
- [x] 离开地图不保留为「下一局地图」；再次进入必须重新生成
- [x] 在地图 UI 展示会话种子或简短会话 id（可仅开发可见，但须能肉眼对比两次）
- [x] 按 Verify 连续进出两次验收

## Notes

- 若 React 卸载已会重建，仍应用显式 session API，避免依赖路由挂载细节
- 不实现持久化存档；内存态即可
- 验证：`pnpm lint` / `pnpm build` 通过；种子 RNG 同种稳定、异种不同。请进出地图两次对比「会话种子」。
