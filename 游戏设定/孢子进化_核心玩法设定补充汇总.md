# 三、对原有设计的影响（已处理）

## 1. 通关目标 → 阶段收益目标

原设定中的固定通关目标，现已改为阶段收益目标 / 探索成就，不再作为强制通关条件。

## 2. 地图设计：关卡 → 生态场

| 原思路 | 新思路 |
|---|---|
| 完成目标后通关 | 达到收益后撤离 |
| 找出口结束关卡 | 出口变成传播机会或撤离加成 |
| 每张地图固定目标 | 每次进入可有不同探索目标 |
| 通关推进 | 资源、进化、传播推进 |

## 3. 孢子化的重要性提高

孢子化是退出地图并固化进化的核心方式。消耗按体量成比例计算（见第六节）。

# 四、当前系统关系

```text
培养皿
  ↓ 出征
地图探索（每次重新生成）
  ↓ 翻格、移动、采集、蔓延
环境压力
  ↓
触发临时进化
  ↓
积累能量
  ↓
孢子化撤离成功
  ↓
进化固化 + 返回培养皿（真实时间恢复）
```

## 核心逻辑

```text
培养皿负责安全恢复（真实时间，角色独立资源）。
地图负责进化和资源获取（每次进入重新生成）。
孢子化负责退出；成功撤离后进化才永久保留。
能量与水分按难度与环境成比例维持消耗。
行动点负责限制每回合操作数量。
```

# 六、已确认规则（数值 / 地图 / 进化 / 培养皿）

## 1. 数值问题（已确认）

| 项目 | 规则 |
|---|---|
| 孢子化退出消耗 | 按当前体量（以当前能量计）扣除 **10%**，结果向上取整，**最低 1 点**；另耗 1 行动点 |
| 基础能量 / 水分消耗 | 按地图难度系数 × 当前格环境恶劣系数成比例扣减（公式见《回合行动规则设定》） |
| 族群与失败 | **族群数量归零即本次探索失败** |

### 补充默认（未另行说明部分）

| 项目 | 第一版默认 |
|---|---|
| 体量定义 | 孢子化结算瞬间的当前能量值 |
| 孢子化公式 | `消耗能量 = max(1, ceil(当前能量 × 0.1))` |
| 孢子化额外 | 不额外强制扣族群；撤离成功后按带回比例转化为孢子库存 |
| 能量不足以支付最低 1 点 | 无法主动孢子化撤离 |
| 动作资源消耗 | 见《回合行动规则设定》第一版消耗表 |
| 能量 / 水分归零 | 进入濒危；若无法在当回合恢复且族群随之归零，则失败 |

---

## 2. 地图问题（已确认）

| 项目 | 规则 |
|---|---|
| 地图生成 | **每次进入重新生成** |
| 局内资源 | 生成后布局固定；采集后该格资源减少/清空，**局内不再额外刷新再生** |
| 长期变量 | **存在**，且不同地区有不同长期变量 |

### 补充默认

| 项目 | 第一版默认 |
|---|---|
| 蔓延痕迹 | 不跨局保留（地图重生成） |
| 局内危险 | 事件与敌人仍会推进；资源点本身不再生 |
| 长期变量内容 | 解锁进度、图鉴、地区声望/生态印象、传播链路等（见《地图区域设定》） |

---

## 3. 进化问题（已确认）

| 项目 | 规则 |
|---|---|
| 进化保留 | **必须孢子化撤离成功**才永久保留；否则仅在当前地图有效 |
| 进化失败 | **不存在失败**；不同环境下进化消耗的资源不同 |
| 异常状态 → 变异 | **第一版不考虑**；上线后再按可玩性评估 |

### 补充默认

| 项目 | 第一版默认 |
|---|---|
| 临时进化 | 本局内立即生效 |
| 失败撤离 / 探索失败 | 本局临时进化全部丢弃 |
| 进化消耗 | 基础消耗 × 环境适配系数（主场更便宜，逆环境更贵） |

---

## 4. 培养皿问题（已确认）

| 项目 | 规则 |
|---|---|
| 自动恢复 | **按真实时间**恢复 |
| 投喂配方 | **无配方**；直接消耗对应资源加速/补充 |
| 资源池 | **不共享**；玩家自行把库存分配给各角色 |
| 培养皿升级 | **暂时不支持** |

### 补充默认

| 项目 | 第一版默认 |
|---|---|
| 自动恢复对象 | 各角色自身族群数量，恢复到该角色当前族群上限 |
| 恢复节奏 | 约每现实 10 分钟恢复 1 点族群（可配置）；离线同样累计，设每日恢复上限 |
| 投喂 | 消耗该角色已分配到的营养/水分等，立即恢复一定族群 |
| 公共库存 | 地图带回的资源先进公共库存，再由玩家手动分配到角色 |
| 出征携带 | 从该角色已分配资源中取出带入地图 |
