# 《孢子进化》回合行动规则设定

## 一、文档定位

本文档用于记录《孢子进化》的基础回合制规则、行动点机制、行动消耗和回合结算方式。

---

# 二、基础回合制结构

游戏采用回合制。

每一回合分为两个阶段：

```text
玩家行动阶段
  ↓
地图结算阶段
```

## 1. 玩家行动阶段

玩家在该阶段消耗行动点执行操作。

## 2. 地图结算阶段

玩家结束行动后，地图进行环境、资源、敌人、菌群消耗等结算。

---

# 三、行动点机制

## 1. 初始行动点

核心菌落每回合初始拥有：

```text
3 点行动点
```

行动点代表当前回合可执行的操作次数。

## 2. 行动点变化

行动点不是固定不变的。随着进化、异常状态、地图环境和角色能力，可以增加或减少。

| 来源 | 行动点变化示例 |
|---|---|
| 移动进化 | 每回合行动点 +1 |
| 高效代谢 | 特定资源充足时行动点 +1 |
| 疲劳状态 | 行动点 -1 |
| 缺水状态 | 行动点 -1 |
| 毒素影响 | 行动点 -1 或禁止某些行动 |
| 孢子化准备 | 行动点锁定或减少 |
| 地图事件 | 水流、干旱、低温等临时降低行动点 |

---

# 四、行动消耗规则

## 1. 行动点消耗

第一版规则：

```text
每个动作都消耗 1 点行动点。
```

也就是说：

| 行动 | 行动点消耗 |
|---|---:|
| 翻格 | 1 |
| 移动 | 1 |
| 采集 | 1 |
| 蔓延 | 1 |
| 进化 | 1 |
| 孢子化 | 1 |
| 使用资源 | 1 |
| 撤离 | 1 |

## 2. 资源消耗不相同

虽然每个动作都消耗 1 点行动点，但不同动作会损失不同资源。

### 第一版行动资源消耗表（默认草案）

基础值再乘以「地图难度系数」，部分行动还会受当前格环境影响。

| 行动 | 行动点 | 能量 | 其他消耗 | 说明 |
|---|---:|---:|---|---|
| 翻格 | 1 | `1 × 难度系数` | — | 探测消耗 |
| 移动 | 1 | `2 × 难度系数` | — | 进入危险格另结算环境伤害 |
| 采集 | 1 | `1 × 难度系数` | — | 采空后该格本局不再刷新 |
| 蔓延 | 1 | `2 × 难度系数` | 营养 `2 × 难度系数`，族群 1 | 占领相邻已揭示格 |
| 进化 | 1 | `3 × 难度系数 × 环境适配系数` | 基因点或对应材料（见进化规则） | 不存在进化失败 |
| 孢子化 | 1 | `max(1, ceil(当前能量 × 0.1))` | — | 体量比例消耗 |
| 使用资源 | 1 | 0 | 消耗所使用的资源 | 例如补水、投喂营养 |
| 撤离 | — | — | — | 第一版并入孢子化，不单列 |

### 地图难度系数（第一版）

| 地图 | 难度系数 |
|---|---:|
| 土壤 | 1.0 |
| 淡水池塘 | 1.1 |
| 腐烂水果 | 1.2 |
| 人体 | 1.5 |
| 污水管道 | 1.6 |
| 极端环境 | 2.0 |

系数参与取整时，结果向上取整，且单项消耗最低为 1（采集在难度 1.0 时能量可为 1）。

# 五、核心行动定义

## 1. 翻格

翻开一个相邻未知六边形格子。

| 项目 | 规则 |
|---|---|
| 消耗 | 1 行动点 + 能量（见上表） |
| 范围 | 默认只能翻核心菌落相邻格 |
| 结果 | 显示资源、危险、敌人、事件、空格等 |
| 扩展 | 部分进化可增加探测范围或预览格子类型 |

---

## 2. 移动

核心菌落移动到相邻已揭示格。

| 项目 | 规则 |
|---|---|
| 消耗 | 1 行动点 + 能量（见上表） |
| 范围 | 默认移动 1 格 |
| 限制 | 通常只能移动到已揭示格 |
| 风险 | 进入危险格、敌人格会触发对应效果 |
| 扩展 | 眼虫等角色可通过进化提升移动能力 |

---

## 3. 采集

采集当前格或已占领格中的资源。

| 项目 | 规则 |
|---|---|
| 消耗 | 1 行动点 + 少量能量 |
| 目标 | 当前格资源，或己方蔓延格资源 |
| 结果 | 获得能量、水分、营养、糖分、矿物质等 |
| 限制 | 资源格采空后变为空格；**本局内不再刷新** |

---

## 4. 蔓延

将菌群扩张到相邻格子，形成蔓延菌落。

| 项目 | 规则 |
|---|---|
| 消耗 | 1 行动点 + 能量 + 营养 + 族群 1 |
| 目标 | 相邻已揭示格 |
| 收益 | 占领区域、连接资源、提供站位 |
| 风险 | 可能被环境事件、敌人、消毒等清除 |
| 跨局 | 地图每次重生成，蔓延痕迹不保留 |

---

## 5. 进化

在地图中满足条件后，选择进化节点。

| 项目 | 规则 |
|---|---|
| 消耗 | 1 行动点 + 能量/基因点/材料（受环境适配系数影响） |
| 发生地点 | 只能在地图中 |
| 培养皿 | 不能进化 |
| 结果 | 本局立即生效（临时进化） |
| 固化 | 必须成功孢子化撤离后才永久保留 |
| 失败 | **不存在进化失败**；只是逆环境消耗更高 |
| 异常变异 | 第一版不做异常状态转进化 |

环境适配系数（补充默认）：

| 情况 | 系数 |
|---|---:|
| 角色主场环境（如酵母在水果） | 0.8 |
| 普通适配 | 1.0 |
| 明显逆环境 | 1.5 |

---

## 6. 孢子化

将核心菌落转化为孢子，用于撤离、保命或传播。

| 项目 | 规则 |
|---|---|
| 消耗 | 1 行动点 + `max(1, ceil(当前能量 × 0.1))` 能量 |
| 用途 | 退出地图、保存成果、固化进化、传播、复苏 |
| 限制 | 能量不足以支付最低 1 点时无法主动撤离 |
| 风险 | 未成功结算前仍可能被事件打断（第一版可简化为结算瞬间判定） |

---

# 六、地图结算阶段

玩家消耗行动点后，地图进行结算。

## 1. 结算内容

| 内容 | 说明 |
|---|---|
| 基础消耗 | 按难度与环境成比例扣除能量、水分（见下） |
| 环境压力 | 干旱、毒素、高温、低温等造成额外影响 |
| 敌人行动 | 敌人移动、扩张、攻击或占领 |
| 资源变化 | **局内不刷新再生**；仅处理本回合采集/事件导致的消耗或转移 |
| 危险扩散 | 毒素、腐败、污染等扩散 |
| 地图事件推进 | 倒计时、周期事件、特殊事件推进 |
| 异常状态更新 | 中毒、缺水、疲劳、孢子化等状态变化 |
| 族群崩溃检查 | 若族群数量归零，判定探索失败 |

## 2. 每回合基础维持消耗（已确认方向）

维持消耗按「地图难度 × 环境恶劣程度」成比例计算。

```text
能量消耗 = max(1, ceil(基础能量消耗 × 难度系数 × 环境恶劣系数 × 体量系数))
水分消耗 = max(1, ceil(基础水分消耗 × 难度系数 × 环境恶劣系数 × 体量系数))
```

| 参数 | 第一版默认 |
|---|---|
| 基础能量消耗 | 2 / 回合 |
| 基础水分消耗 | 2 / 回合 |
| 难度系数 | 同行动消耗表（土壤 1.0 … 极端 2.0） |
| 体量系数 | `1 + floor(当前族群 / 20) × 0.1`（族群越大维持越贵） |

### 环境恶劣系数（当前格 / 当前事件）

| 环境状态 | 恶劣系数 |
|---|---:|
| 安全 / 适宜 | 0.8 |
| 普通 | 1.0 |
| 轻度压力（干燥、弱毒、低温等） | 1.3 |
| 中度压力 | 1.6 |
| 重度压力 / 事件爆发中 | 2.0 |

蔓延菌落额外维持：每 3 个已占领蔓延格，额外 +1 能量（向上取整），同样乘难度系数。

# 七、行动点与资源的设计关系

行动点控制“每回合做几件事”。

资源控制“能不能持续做这些事”。

```text
行动点限制操作频率。
资源限制长期生存。
难度与环境放大维持与行动消耗。
```

例如：

| 情况 | 结果 |
|---|---|
| 行动点多但能量少 | 可以做很多事，但很快耗尽能量 |
| 能量多但行动点少 | 资源充足，但每回合操作有限 |
| 高难度地图 | 同样行动与维持更贵，逼迫更谨慎 |
| 进化提升行动点 | 节奏更快，但资源消耗也更快 |
| 异常状态降低行动点 | 玩家需要优先处理生存问题 |

# 八、第一版建议规则

第一版采用以下简化规则：

```text
每回合 3 点行动点。
每个动作消耗 1 点行动点。
行动与维持消耗随地图难度和环境恶劣程度放大。
孢子化按当前能量 10% 扣费，最低 1 点。
局内资源采后不再生。
行动点归零后进入地图结算阶段。
```

## 第一版行动列表

```text
翻格
移动
采集
蔓延
进化
孢子化
使用资源
```

# 九、其他第一版约定（补充）

| 项目 | 规则 |
|---|---|
| 跳过行动 | 允许；可提前结束行动阶段进入结算 |
| 撤销行动 | 不允许 |
| 角色行动点差异 | 第一版统一 3 点；进化可 +1 |
| 连续行动奖励 | 不做 |
