# 《孢子进化》地图区域设定文档

## 一、地图设计目标

本游戏以“微生物生存、繁殖、进化、传播”为核心。地图区域不只是背景，而是推动玩家选择进化方向的主要系统。

地图定位为可反复进入的**进化场**，不是一次性关卡：

```text
不设固定通关条件。
进入地图是为了获取资源、承受压力、触发进化、制造孢子。
玩家可随时尝试孢子化撤离；传播格提供传播机会或撤离加成。
各地图的特殊机制和阶段收益目标用于引导探索，而非强制通关。
每次进入重新生成布局；局内资源采后不再生。
跨局保留地区长期变量，而不是具体格子状态。
```

每个地图区域应包含以下要素：

| 要素 | 设计作用 |
|---|---|
| 资源 | 决定玩家为什么进入该区域 |
| 环境压力 | 逼迫玩家进化或改变策略 |
| 竞争者 | 提供生态冲突 |
| 特殊机制 | 让不同地图玩法产生差异 |
| 适合角色 | 让不同微生物有明确优势区 |
| 阶段收益目标 | 引导单次探索方向，完成后给额外奖励，但不强制通关 |
| 难度系数 | 放大行动与维持消耗 |
| 长期变量 | 跨局记录该地区的解锁、印象与传播进度 |

# 二点五、地图生成与长期变量

## 1. 每次进入重新生成

| 项目 | 规则 |
|---|---|
| 布局 | 每次进入按该地图参数重新随机生成 |
| 资源 | 生成时写入格子；本局采后减少/清空，**不再额外刷新** |
| 敌人 / 事件 | 按生成表放置；事件仍可随回合推进 |
| 蔓延痕迹 | 不跨局保留 |
| 落点 | 仍在安全格随机落入，并揭示周围 6 邻格 |

## 2. 地区长期变量（跨局保留）

长期变量不保存具体格子，而保存该地区的进度与“生态印象”，并可轻微影响下次生成权重。

| 地图 | 长期变量示例 | 作用 |
|---|---|---|
| 全图通用 | 解锁状态、探索次数、图鉴完成度、阶段成就 | 记录进度、解锁传播 |
| 土壤 | 干旱熟悉度、根际发现次数 | 略提高安全格/根际格权重 |
| 淡水池塘 | 光照层熟悉度、传播成功次数 | 略提高光照格与传播格权重 |
| 腐烂水果 | 最高腐败耐受回合、发酵进化次数 | 略提高糖分热点权重 |
| 人体 | 免疫遭遇次数、抗药线索 | 略降低开局极端敌人格密度（熟练减免） |
| 污水管道 | 生物膜据点建立次数、消毒存活次数 | 略提高附着点权重 |
| 极端环境 | 抗性门槛达成记录、古老孢子线索 | 解锁更深层分支生成 |

说明：长期变量只做轻度偏向，不能变成“固定刷点地图”。

## 3. 难度与消耗

各地图难度系数用于放大：

- 行动资源消耗；
- 每回合能量 / 水分维持消耗；
- 部分事件强度。

详见《回合行动规则设定》。

# 三、地图一：土壤

## 1. 地图定位

**基础新手区 / 生存进化区**

土壤是最适合作为第一张地图的区域。它包含水分、有机物、矿物质、植物根系、其他微生物和干湿周期，能够自然引出资源采集、繁殖、竞争、休眠、孢子化等基础玩法。

## 2. 环境特点

| 特点 | 游戏表现 |
|---|---|
| 有机物丰富 | 提供基础营养资源 |
| 干湿变化明显 | 干旱时普通细胞生存压力上升 |
| 微生物种类多 | 有竞争、捕食、共生关系 |
| 空间结构复杂 | 适合探索、扩张和躲避 |
| 植物根系存在 | 可提供额外糖分和共生玩法 |

## 3. 核心资源

| 资源 | 作用 |
|---|---|
| 腐殖质 | 基础营养来源 |
| 水分 | 维持细胞活动和繁殖 |
| 矿物质 | 用于防御、抗性类进化 |
| 根系分泌物 | 高价值稳定资源 |
| 死亡微生物残骸 | 可被分解利用 |

## 4. 环境压力

| 压力 | 影响 |
|---|---|
| 干旱 | 降低移动和繁殖效率，普通细胞死亡率上升 |
| 营养不足 | 迫使玩家迁移或进入休眠 |
| 捕食性微生物 | 威胁弱小菌群 |
| 酸碱变化 | 影响不同角色的生存效率 |
| 土壤裂缝 | 改变路径和扩张路线 |

## 5. 特殊机制

| 机制名 | 机制说明 |
|---|---|
| 干旱周期 | 地图周期性缺水，触发休眠和孢子玩法 |
| 腐殖质热点 | 随机出现高营养区域，引导玩家争夺 |
| 根际区域 | 靠近植物根系时获得稳定资源 |
| 孢子保存 | 孢子形态可以跨越恶劣周期 |
| 土壤孔隙 | 小型单位可以穿越，群体单位需要进化适应 |

## 6. 适合角色

| 角色 | 适配原因 |
|---|---|
| 芽孢杆菌 | 可以通过芽孢抵抗干旱和营养不足 |
| 网柄菌 | 饥荒时可聚集形成孢子塔 |
| 黏细菌 | 适合在土壤中群体捕食其他微生物 |
| 酵母菌 | 可在富含腐殖质或腐烂果实附近生存 |

## 7. 玩法重点

土壤地图的核心是“活下去”。玩家需要在繁殖和保存实力之间做选择：资源充足时扩张，环境恶化时休眠或孢子化撤离。

### 阶段收益目标示例（非通关条件）

| 目标 | 说明 |
|---|---|
| 熬过干旱 | 在至少 1 次干旱周期中存活 |
| 带回能量 | 孢子化撤离时带回足够能量支持培养皿 |
| 解锁耐干燥 | 触发芽孢/抗干燥相关进化 |

# 四、地图二：淡水池塘

## 1. 地图定位

**光照探索区 / 水域生态区**

淡水池塘适合引入光照、水流、营养分层和水域移动机制。它能让蓝细菌、眼虫等角色获得主场优势。

## 2. 环境特点

| 特点 | 游戏表现 |
|---|---|
| 光照充足 | 表层适合光合作用 |
| 水流存在 | 单位可能被动漂移 |
| 营养分层 | 表层、底层、岸边资源不同 |
| 捕食者较多 | 提高生存压力 |
| 氧气变化明显 | 不同区域适合不同微生物 |

## 3. 核心资源

| 资源 | 作用 |
|---|---|
| 光照 | 蓝细菌和眼虫的重要能量来源 |
| 溶解有机物 | 通用营养资源 |
| 水中矿物质 | 支持基础进化 |
| 浮游残骸 | 中高价值资源 |
| 岸边腐殖质 | 连接土壤地图的过渡资源 |

## 4. 环境压力

| 压力 | 影响 |
|---|---|
| 水流冲刷 | 单位可能被带离资源区 |
| 光照不足 | 光合单位能量下降 |
| 缺氧层 | 影响好氧微生物 |
| 捕食者 | 威胁单体单位 |
| 水体污染 | 改变水域生态，造成毒性压力 |

## 5. 特殊机制

| 机制名 | 机制说明 |
|---|---|
| 光照层 | 越靠近水面，光照越强 |
| 缺氧层 | 水底氧气不足，适合特定进化路线 |
| 水流漂移 | 单位会随水流移动，需要机动或附着能力 |
| 藻华爆发 | 蓝细菌扩张到一定规模后改变整片水域 |
| 浮游迁移 | 眼虫等机动单位可以快速寻找资源斑块 |

## 6. 适合角色

| 角色 | 适配原因 |
|---|---|
| 蓝细菌 | 可以利用光照进行能量生产 |
| 眼虫 | 具有移动能力和趋光能力 |
| 芽孢杆菌 | 可通过孢子漂流扩散 |
| 黏细菌 | 可在水底或生物膜区域作为变体出现 |

## 7. 玩法重点

淡水池塘的核心是“抢光”和“抗流”。玩家需要控制光照区域，同时避免被水流冲走。蓝细菌偏铺场，眼虫偏探索。收益足够后可通过孢子化撤离；占领传播格可提高进入新地图的机会。

### 阶段收益目标示例（非通关条件）

| 目标 | 说明 |
|---|---|
| 占领光照格 | 占领一定数量光照格并维持若干回合 |
| 完成传播 | 触发一次水流/昆虫传播事件 |
| 光合进化 | 解锁弱光适应或藻膜相关进化 |

# 五、地图三：腐烂水果

## 1. 地图定位

**高资源爆发区 / 快速繁殖区**

腐烂水果是一个资源丰富但生命周期短的区域。它适合酵母菌快速繁殖，也适合引入发酵、腐败、竞争和区域倒计时机制。

## 2. 环境特点

| 特点 | 游戏表现 |
|---|---|
| 糖分极高 | 支持快速繁殖 |
| 生命周期短 | 地图会逐渐腐败、干燥或被吃掉 |
| 微生物竞争强 | 细菌、真菌、霉菌争夺资源 |
| 代谢产物明显 | 酒精、酸性物质可改变环境 |
| 易传播 | 可通过昆虫、动物、风扩散到新区域 |

## 3. 核心资源

| 资源 | 作用 |
|---|---|
| 糖分 | 酵母菌的核心资源 |
| 果肉组织 | 通用营养来源 |
| 水分 | 维持微生物活性 |
| 发酵产物 | 可作为特殊资源或环境武器 |
| 果皮裂口 | 扩张入口和传播通道 |

## 4. 环境压力

| 压力 | 影响 |
|---|---|
| 腐败倒计时 | 时间越久，地图越不稳定，压迫玩家选择撤离时机 |
| 干燥 | 降低细胞活动 |
| 竞争微生物 | 与玩家争夺糖分 |
| 酸化 | 影响不耐酸单位 |
| 被动物吃掉 | 可能强制结束本次探索并结算，也可能进入人体或动物肠道 |

## 5. 特殊机制

| 机制名 | 机制说明 |
|---|---|
| 糖分热点 | 高能量区域，适合快速扩张 |
| 发酵区域 | 酵母菌可把糖分转化为酒精、酸或气体 |
| 腐败倒计时 | 时间越久，地图越不稳定 |
| 昆虫传播 | 占领特定区域后可搭乘昆虫前往新地图 |
| 被食用事件 | 食物被吃掉后，玩家可能进入人体地图 |

## 6. 适合角色

| 角色 | 适配原因 |
|---|---|
| 酵母菌 | 主场，可快速利用糖分 |
| 芽孢杆菌 | 可在水果干燥后通过孢子存活 |
| 黏细菌 | 可捕食其他竞争微生物 |
| 网柄菌 | 可在资源枯竭时聚集并迁移 |

## 7. 玩法重点

腐烂水果的核心是“快”。玩家需要在资源衰败前尽快扩张、繁殖、发酵，并在合适时机孢子化撤离；果皮裂口、昆虫等传播格提供进入新地图的加成，不是强制出口通关。

### 阶段收益目标示例（非通关条件）

| 目标 | 说明 |
|---|---|
| 糖分爆发 | 腐败加剧前带回大量糖分 |
| 发酵进化 | 触发发酵/快速繁殖相关进化 |
| 昆虫传播 | 占领传播相关区域并成功触发传播事件 |

# 六、地图四：人体

## 1. 地图定位

**高资源高风险区 / 中期复杂生态区**

人体是一个资源丰富但风险极高的地图。它可以分为口腔、胃部、肠道、皮肤、呼吸道、伤口等子区域。人体适合放在中期，因为这里涉及免疫系统、体温、药物、菌群竞争等复杂机制。

## 2. 子区域设计

| 子区域 | 特点 | 适合玩法 |
|---|---|---|
| 口腔 | 糖分较多，菌群竞争强 | 快速繁殖、黏附、酸化 |
| 胃部 | 强酸环境 | 耐酸进化、生存挑战 |
| 肠道 | 营养丰富，菌群密集 | 资源争夺、生态位竞争 |
| 皮肤 | 干燥、盐分、油脂 | 抗干燥、附着、防御 |
| 呼吸道 | 湿润，有免疫压力 | 传播、躲避清除 |
| 伤口 | 营养高，免疫反应强 | 战斗、扩张、抗免疫 |

## 3. 核心资源

| 资源 | 作用 |
|---|---|
| 糖分 | 支持快速繁殖 |
| 蛋白质残留 | 中高价值营养 |
| 脂质 | 皮肤区域资源 |
| 黏液 | 可作为屏障或通道 |
| 组织液 | 伤口区域高价值资源 |
| 菌群生态位 | 占据后获得长期收益 |

## 4. 环境压力

| 压力 | 影响 |
|---|---|
| 免疫系统 | 白细胞、抗菌物质会清除微生物 |
| 体温变化 | 发烧时造成高温压力 |
| 胃酸 | 对不耐酸单位造成持续伤害 |
| 抗生素 | 大范围杀伤非抗性单位 |
| 原生菌群 | 与玩家争夺空间和资源 |
| 清洁行为 | 洗手、刷牙、消毒等导致区域清理 |

## 5. 特殊机制

| 机制名 | 机制说明 |
|---|---|
| 免疫巡逻 | 免疫单位在地图中巡逻并清除异常微生物 |
| 抗生素冲击 | 随机或剧情触发的大范围压力事件 |
| 菌群平衡 | 过度扩张可能触发更强免疫反应 |
| 黏附系统 | 能否附着在组织表面决定能否长期生存 |
| 发烧事件 | 提高整体温度，迫使玩家进化耐热或休眠 |
| 入口传播 | 通过食物、空气、伤口进入人体不同区域 |

## 6. 适合角色

| 角色 | 适配原因 |
|---|---|
| 芽孢杆菌 | 可通过芽孢抵抗药物、干燥和高温 |
| 酵母菌 | 可在口腔、肠道等糖分环境中繁殖 |
| 黏细菌 | 可作为捕食型或竞争型菌群角色 |
| 网柄菌 | 可在特定组织环境中设计为群体协作玩法 |

## 7. 玩法重点

人体地图的核心是“高收益与高风险”。玩家不能无脑扩张，否则会触发免疫系统或药物清除。需要在隐藏、附着、繁殖、抗性之间做选择，并在危险升高前孢子化撤离保存成果。

### 阶段收益目标示例（非通关条件）

| 目标 | 说明 |
|---|---|
| 抗免疫存活 | 被免疫追击后成功存活并撤离 |
| 占据生态位 | 短期占据一个菌群生态位并带回资源 |
| 耐酸/抗药进化 | 触发对应抗性进化 |

# 七、地图五：污水管道

## 1. 地图定位

**污染毒性区 / 生物膜争夺区**

污水管道是一个高营养、高毒性、高流动性的地图。它适合设计成中后期地图，引入污染资源、生物膜据点、水流冲刷和消毒事件。

## 2. 环境特点

| 特点 | 游戏表现 |
|---|---|
| 有机物多 | 资源丰富但不稳定 |
| 毒素多 | 需要抗毒进化 |
| 水流强 | 冲刷弱小群落 |
| 生物膜多 | 适合占领据点 |
| 人工干预强 | 会发生清洗和消毒事件 |

## 3. 核心资源

| 资源 | 作用 |
|---|---|
| 有机废物 | 基础营养来源 |
| 污染物 | 高风险特殊资源 |
| 管壁附着点 | 建立生物膜据点 |
| 微生物残骸 | 可分解利用 |
| 化学物质 | 解锁抗毒或特殊代谢进化 |

## 4. 环境压力

| 压力 | 影响 |
|---|---|
| 毒素 | 持续削弱普通细胞 |
| 水流冲刷 | 周期性带走未附着单位 |
| 消毒剂 | 大范围杀伤事件 |
| 缺氧 | 管道深处氧气不足 |
| 高密度竞争 | 其他微生物大量存在 |
| pH 波动 | 酸碱变化频繁 |

## 5. 特殊机制

| 机制名 | 机制说明 |
|---|---|
| 污染资源 | 高收益但带毒性，需要抗性才能稳定利用 |
| 生物膜据点 | 占领管壁后获得防御和资源加成 |
| 水流冲刷 | 周期性清理浮游单位 |
| 消毒事件 | 人类清洁导致大规模危机 |
| 管道分支 | 可通过水流进入不同地图区域 |
| 毒性适应 | 长期接触污染物后可解锁抗毒进化 |

## 6. 适合角色

| 角色 | 适配原因 |
|---|---|
| 黏细菌 | 适合群体行动和生物膜争夺 |
| 芽孢杆菌 | 能抵抗消毒和毒性环境 |
| 酵母菌 | 可利用丰富有机物 |
| 蓝细菌 | 只适合有光照的浅层或开放排水区 |

## 7. 玩法重点

污水管道的核心是“占点”和“抗毒”。玩家需要建立生物膜据点，避免被水流冲走，同时进化出利用污染资源的能力。消毒事件前后是关键撤离窗口。

### 阶段收益目标示例（非通关条件）

| 目标 | 说明 |
|---|---|
| 建立生物膜 | 占领并维持管壁据点 |
| 抗毒进化 | 利用污染资源并解锁抗毒 |
| 扛过消毒 | 在一次消毒事件中存活后孢子化撤离 |

# 八、地图六：极端环境

## 1. 地图定位

**高级挑战区 / 稀有进化资源区**

极端环境可以分为温泉、火山口、冰川、冻土、强酸湖、强盐湖等。第一版可以先选“温泉/火山口”或“冰川/冻土”作为代表，不必全部做。

## 2. 环境分支

| 分支 | 特点 | 推荐玩法 |
|---|---|---|
| 温泉 / 火山口 | 高温、矿物丰富、酸碱异常 | 耐热、抗酸、矿物进化 |
| 冰川 / 冻土 | 低温、资源冻结、短暂融化期 | 休眠、抗冻、周期爆发 |
| 强酸湖 | 高酸环境，普通单位难以生存 | 抗酸进化 |
| 强盐湖 | 高盐环境，脱水压力强 | 耐盐进化 |

## 3. 核心资源

| 资源 | 作用 |
|---|---|
| 稀有矿物 | 解锁高级抗性进化 |
| 热能 | 可作为特殊能量来源 |
| 冰封有机物 | 融化期释放资源 |
| 盐晶 / 酸性物质 | 用于特殊代谢或防御技能 |
| 古老孢子 | 可作为剧情或进化素材 |

## 4. 环境压力

| 压力 | 影响 |
|---|---|
| 高温 | 普通细胞持续受损 |
| 低温 | 活动和繁殖速度大幅下降 |
| 强酸 / 强碱 | 腐蚀细胞结构 |
| 高盐 | 导致脱水压力 |
| 紫外线 | 表层区域造成额外伤害 |
| 资源稀少 | 迫使玩家精细规划行动 |

## 5. 特殊机制

| 机制名 | 机制说明 |
|---|---|
| 热浪喷发 | 周期性高伤害事件 |
| 融化窗口 | 冰川地图中短时间释放资源 |
| 矿物结晶 | 稀有进化资源刷新点 |
| 极限休眠 | 孢子形态可长期保存 |
| 古老复苏 | 解锁远古微生物或特殊技能 |
| 极限适应 | 只有具备对应抗性的角色才能长期生存 |

## 6. 适合角色

| 角色 | 适配原因 |
|---|---|
| 芽孢杆菌 | 最适合极端环境，能休眠和复苏 |
| 蓝细菌 | 可设计耐热或耐寒光合分支 |
| 网柄菌 | 可在短暂适宜窗口中聚集传播 |
| 酵母菌 | 可设计耐寒或耐盐分支 |

## 7. 玩法重点

极端环境的核心是“抗性门槛”。玩家进入前需要准备对应进化，否则难以生存。这里适合作为高级进化材料产地或剧情后期区域；达成抗性挑战后孢子化撤离即可，无需通关出口。

### 阶段收益目标示例（非通关条件）

| 目标 | 说明 |
|---|---|
| 抗性挑战 | 在对应极端压力下存活若干回合 |
| 稀有矿物 | 带回稀有进化材料 |
| 古老孢子 | 发现并带回古老孢子相关线索 |

# 十一、地图之间的传播关系

不同地图之间可以通过“传播事件”连接，而不是简单选关。

| 起点地图 | 传播方式 | 目标地图 |
|---|---|---|
| 土壤 | 雨水冲刷 | 淡水池塘 |
| 土壤 | 植物结果 / 腐烂 | 腐烂水果 |
| 腐烂水果 | 被人或动物食用 | 人体 |
| 人体 | 排泄物 / 污水系统 | 污水管道 |
| 污水管道 | 排放 / 河流连接 | 淡水池塘或海洋 |
| 土壤 / 冰层 | 古老孢子复苏 | 极端环境 |
| 淡水池塘 | 水鸟、昆虫、风 | 其他水域或人体入口 |

# 十二、地图系统设计建议

## 1. 地图是进化场，不是关卡

| 原思路 | 新思路 |
|---|---|
| 完成目标后通关 | 达到收益后孢子化撤离 |
| 找出口结束关卡 | 传播格提供传播机会或撤离加成 |
| 每张地图固定通关目标 | 每次进入可有不同阶段收益目标 |
| 通关推进 | 资源、进化、传播推进 |

## 2. 不同地图必须有明确差异

不要让所有地图都只是“资源点 + 敌人”。每张地图至少要有一个主机制：

| 地图 | 主机制 |
|---|---|
| 土壤 | 干湿周期 |
| 淡水池塘 | 光照层和水流 |
| 腐烂水果 | 腐败倒计时（压迫撤离时机，而非通关倒计时） |
| 人体 | 免疫系统 |
| 污水管道 | 生物膜据点和毒素 |
| 极端环境 | 抗性门槛 |

## 3. 地图要推动进化选择

例如：

| 环境压力 | 对应进化 |
|---|---|
| 干旱 | 芽孢化、厚壁强化 |
| 光照不足 | 色素进化、混合营养 |
| 高糖资源 | 出芽繁殖、发酵代谢 |
| 免疫清除 | 黏附、隐蔽、抗免疫 |
| 毒素污染 | 抗毒代谢、生物膜保护 |
| 高温低温 | 耐热、抗冻、休眠 |

## 4. 地图之间要能形成生态链

推荐形成这样的整体路线：

```text
土壤生态
  ↓ 雨水冲刷
淡水池塘
  ↓ 昆虫或动物传播
腐烂水果
  ↓ 被食用
人体
  ↓ 排泄物进入城市系统
污水管道
  ↓ 排放或泄漏
回到自然水体 / 土壤

极端环境作为支线高级挑战区
```

地图解锁主要通过传播事件与探索记录推进，而不是“通关下一关”。

# 十三、第一版开发建议

如果开发资源有限，建议先做 3 张核心地图：

```text
土壤
淡水池塘
腐烂水果
```

原因：

| 地图 | 原因 |
|---|---|
| 土壤 | 能承载孢子化、生存、基础资源系统 |
| 淡水池塘 | 能承载光照、水流、探索系统 |
| 腐烂水果 | 能承载高资源、快速繁殖、限时压迫撤离玩法 |

第一版规则对齐：

```text
六边形格子地图
每回合 3 行动点
无固定通关条件
孢子化是主要退出方式（能量 10%，最低 1）
每次进入重新生成，局内资源不再生
各地图有难度系数与长期变量
进化撤离成功才永久保留
各地图用阶段收益目标引导探索
```

第二阶段再加入：

```text
人体
污水管道
极端环境
```

这样系统会更稳定，不会一开始就被人体免疫、抗生素、复杂菌群等机制拖得太重。

# 十四、最终推荐 6 地图

```text
1. 土壤：生存、休眠、孢子
2. 淡水池塘：光照、水流、探索
3. 腐烂水果：糖分、发酵、快速繁殖
4. 人体：免疫、药物、菌群竞争
5. 污水管道：毒素、生物膜、污染资源
6. 极端环境：高温/低温、抗性、稀有进化
```

这 6 张地图能够覆盖游戏早期到后期的主要体验：基础生存、资源爆发、生态扩张、复杂对抗、区域占领和高级进化。
