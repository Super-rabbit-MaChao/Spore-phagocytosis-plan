# 《孢子进化》视觉与地图表现设定

## 一、文档定位

本文档用于记录《孢子进化》的画面视角、美术风格、地图格子表现、角色表现方式，以及不同环境地图的视觉区分规则。

---

# 二、整体视觉方向

## 1. 画面视角

游戏采用：

```text
2D 俯视视角
```

玩家从上方观察地图格子、核心菌落、蔓延菌落、资源、危险和环境事件。

该视角适合：

- 翻格子探索；
- 六边形地图；
- 微生物菌落扩张；
- 回合制策略操作；
- 地图状态信息展示。

---

## 2. 美术风格

游戏采用：

```text
科普绘本风
```

风格目标不是写实恐怖，也不是纯卡通，而是偏“显微镜下的生态绘本”。

### 风格关键词

| 关键词 | 说明 |
|---|---|
| 科普感 | 角色和地图来源于真实微生物、真实环境 |
| 绘本感 | 画面柔和，适合长期观看 |
| 生态感 | 地图表现不同环境的生态差异 |
| 微观感 | 资源、菌落、毒素、孢子都像显微世界元素 |
| 轻策略感 | 信息清晰，不追求过度复杂的写实细节 |

---

# 三、格子表现

## 1. 格子类型

游戏地图使用：

```text
六边形格子
```

## 2. 使用六边形的原因

| 原因 | 说明 |
|---|---|
| 邻接关系自然 | 每个格子有 6 个相邻方向 |
| 适合扩张表现 | 菌落蔓延时比方格更自然 |
| 视觉更接近生态斑块 | 比普通棋盘更有生物群落感 |
| 策略选择更丰富 | 移动与蔓延方向更有变化 |

---

## 3. 格子状态表现

| 格子状态 | 视觉表现 |
|---|---|
| 未揭示格 | 深色迷雾、模糊纹理、未知图标 |
| 已揭示格 | 显示地形、资源、危险或敌人 |
| 核心菌落格 | 使用明显高亮背景或外圈描边 |
| 蔓延菌落格 | 使用较浅的己方菌落背景色 |
| 资源格 | 显示资源图标和轻微闪光 |
| 危险格 | 显示警告纹理、腐蚀、干裂、毒雾等 |
| 敌人格 | 显示敌对菌群或捕食者图标 |
| 传播格 | 显示气流、水流、昆虫、裂口等传播符号（传播机会 / 撤离加成，非强制通关） |

---

# 四、角色表现

## 1. 角色表现方式

角色使用：

```text
对应的菌落图标表现
```

不是表现成单个拟人角色，而是表现成一个“微生物核心菌落”。

## 2. 核心菌落与蔓延菌落区分

通过背景颜色、亮度和边框区分：

| 类型 | 表现方式 |
|---|---|
| 核心菌落 | 颜色更饱和，有明显外圈、高亮或轻微动态呼吸效果 |
| 蔓延菌落 | 颜色较浅，铺在格子背景上，表现为扩散中的菌膜或菌斑 |
| 危险中的菌落 | 闪烁、萎缩、颜色变灰或出现裂纹 |
| 孢子化菌落 | 收缩成颗粒状、外壳变厚、颜色降低饱和度 |
| 复苏菌落 | 从孢子颗粒重新扩散成菌落图标 |

---

## 3. 不同角色图标方向

| 角色 | 图标表现建议 |
|---|---|
| 芽孢杆菌 | 椭圆或短杆状菌落，孢子形态有厚壳 |
| 蓝细菌 | 蓝绿色藻膜、链状或片状菌群 |
| 酵母菌 | 圆形出芽细胞，多个小圆泡聚集 |
| 网柄菌 | 变形虫状群体，可出现聚集流线 |
| 眼虫 | 单体感更强，有鞭毛和眼点符号 |
| 黏细菌 | 黏膜状群体，边缘有滑行扩散感 |

---

# 五、地图环境表现

地图要根据环境明显区分，而不是只换名字。

## 1. 环境区分原则

不同地图应该在以下方面有差异：

| 表现维度 | 示例 |
|---|---|
| 主色调 | 土壤偏棕，池塘偏蓝绿，水果偏橙红 |
| 地形纹理 | 土粒、水纹、果肉、组织、管壁、冰晶等 |
| 资源图标 | 糖分、水滴、矿物、光斑、有机物等 |
| 危险表现 | 干裂、毒雾、酸液、免疫巡逻、热浪等 |
| 动态效果 | 水流、腐败扩散、毒素扩散、免疫移动等 |

---

## 2. 六个地图的视觉方向

| 地图 | 主色调 | 视觉元素 | 氛围 |
|---|---|---|---|
| 土壤 | 棕色、暗绿 | 土粒、腐殖质、根系、水滴 | 基础生态、生存 |
| 淡水池塘 | 蓝绿、浅青 | 水纹、光斑、浮游颗粒、藻膜 | 明亮、流动、探索 |
| 腐烂水果 | 橙红、紫褐 | 果肉、糖晶、发酵气泡、腐败斑 | 高资源、短暂、竞争 |
| 人体 | 粉红、暗红、乳白 | 黏液、组织纹理、免疫单位、酸液 | 高风险、高资源 |
| 污水管道 | 灰绿、暗黄 | 管壁、生物膜、毒雾、污泥、水流 | 污染、压迫、占点 |
| 极端环境 | 冰蓝/熔岩红 | 冰晶、热泉、矿物结晶、酸雾 | 高压、高级挑战 |

# 六、视觉优先级

第一版不用做复杂动画，优先保证信息清晰。

## 第一版必须有

```text
1. 六边形格子地图
2. 未揭示 / 已揭示状态
3. 核心菌落和蔓延菌落的明显区分
4. 资源格、危险格、敌人格、事件格的基础图标
5. 不同地图的主色调和背景差异
```

## 后续再增强

```text
1. 菌落扩散动画
2. 孢子化动画
3. 资源吸收粒子
4. 危险扩散特效
5. 地图事件动态表现
6. 显微镜扫描感 UI
```

---

# 七、最终设定摘要

```text
游戏采用 2D 俯视视角。
整体美术风格为科普绘本风。
地图使用六边形格子。
角色以对应微生物的菌落图标表现。
核心菌落和蔓延菌落通过背景颜色、亮度、边框区分。
地图根据不同生态环境使用不同主色调、纹理和动态表现。
```
