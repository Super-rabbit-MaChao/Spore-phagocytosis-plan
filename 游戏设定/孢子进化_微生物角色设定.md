# 《孢子进化》微生物角色设定文档

## 1. 项目定位

本游戏以“微生物进化”为核心主题。玩家从原始微生物开始，在不同环境中寻找资源、适应压力、解锁进化路线，最终发展出具有不同生存策略的微生物族群。

本设定不追求完全还原真实生物学比例，而是提取现实微生物的核心特征，转化为可理解、可操作、可成长的游戏角色与职业体系。

---

## 2. 角色总览

| 角色名 | 生物原型 | 角色定位 | 职业方向 | 核心关键词 |
|---|---|---|---|---|
| 芽孢杆菌 | Bacillus | 生存防御型 | 生存者 / 坦克 | 休眠、抗性、复苏 |
| 蓝细菌 | Cyanobacteria | 光合扩张型 | 生态改造者 / 生产者 | 光合作用、产氧、扩张 |
| 酵母菌 | Yeast | 繁殖生产型 | 工程师 / 爆兵者 | 出芽、发酵、资源转化 |
| 网柄菌 | Dictyostelium | 群体协作型 | 组织者 / 召唤师 | 聚集、分工、孢子塔 |
| 眼虫 | Euglena | 探索机动型 | 斥候 / 游击者 | 鞭毛、趋光、双能源 |
| 黏细菌 | Myxobacteria | 群体掠食型 | 猎手 / 军团 | 围猎、滑行、子实体 |

---

# 3. 角色设定

---

## 3.1 芽孢杆菌

### 角色名

**芽孢杆菌**

### 生物特点

芽孢杆菌的核心特点是可以形成“芽孢”。当环境恶劣时，它可以进入休眠状态，大幅降低生命活动，抵抗高温、干旱、毒素、营养不足等压力。

在游戏中，芽孢杆菌代表“极限生存路线”。

### 职业定位

**生存者 / 坦克**

适合新手使用，容错率高，不容易死亡。它不一定繁殖最快，也不一定攻击最强，但在恶劣环境下最稳定。

### 进化路线

```text
原始细菌
  ↓
厚壁细胞
  ↓
休眠芽孢
  ↓
抗逆芽孢体
  ↓
极限环境适应者
```

### 核心技能

| 技能名 | 技能效果 |
|---|---|
| 芽孢化 | 进入休眠状态，降低能量消耗，大幅提升抗性 |
| 厚壁强化 | 提升对毒素、物理伤害和环境压力的防御 |
| 环境预警 | 提前感知高温、干旱、酸碱变化等危险 |
| 复苏萌发 | 环境恢复后快速苏醒，并进入短暂加速繁殖状态 |
| 极限耐受 | 在其他微生物无法生存的区域中继续存活 |

### 玩法总结

芽孢杆菌适合做游戏初期角色。它的玩法重点不是主动进攻，而是“活下来”。玩家需要判断什么时候继续繁殖，什么时候进入芽孢状态保存实力。

---

## 3.2 蓝细菌

### 角色名

**蓝细菌**

可选游戏化名称：

- 蓝藻菌群
- 光合菌群
- 原始光能菌

### 生物特点

蓝细菌可以利用光照进行光合作用，把环境中的光能转化为自身能量。它们可以大规模扩张，并改变周围生态环境。

在游戏中，蓝细菌代表“环境改造路线”。

### 职业定位

**生态改造者 / 生产者**

适合喜欢铺场、经营、扩张的玩家。蓝细菌在有光环境中优势明显，但在黑暗、深水或被遮挡区域会受到限制。

### 进化路线

```text
原始蓝细菌
  ↓
光合细胞
  ↓
群体藻膜
  ↓
高效产氧菌群
  ↓
生态改造者
```

### 核心技能

| 技能名 | 技能效果 |
|---|---|
| 光合作用 | 在有光区域自动产生能量 |
| 色素进化 | 提升对不同光照环境的适应能力 |
| 藻膜扩张 | 在水面或潮湿地表快速占领区域 |
| 产氧冲击 | 提高局部氧气浓度，压制厌氧型敌人 |
| 光域同化 | 将普通区域转化为适合自身生长的光合区域 |

### 玩法总结

蓝细菌适合做“地图控制型”角色。它需要争夺光照区域，通过持续扩张改变环境，把普通地图逐渐改造成自己的优势生态区。

---

## 3.3 酵母菌

### 角色名

**酵母菌**

### 生物特点

酵母菌擅长利用糖分，并通过出芽方式快速繁殖。它还能进行发酵，把资源转化成其他代谢产物。

在游戏中，酵母菌代表“资源转化与快速繁殖路线”。

### 职业定位

**工程师 / 爆兵者**

适合喜欢资源运营、快速扩张、数量压制的玩家。酵母菌在资源充足时非常强，但在资源贫瘠区域会明显乏力。

### 进化路线

```text
原始酵母
  ↓
出芽繁殖体
  ↓
高效发酵菌群
  ↓
菌落工厂
  ↓
资源转化核心
```

### 核心技能

| 技能名 | 技能效果 |
|---|---|
| 出芽繁殖 | 消耗糖分快速产生新个体 |
| 发酵代谢 | 将糖分转化为特殊资源 |
| 酒精毒雾 | 释放代谢产物，对部分敌人造成抑制 |
| 菌落工厂 | 提升整个族群的资源转化效率 |
| 糖分感知 | 发现附近高营养区域 |

### 玩法总结

酵母菌适合做经济型角色。它的关键是找到糖分资源，然后快速扩张。它不是最耐打的角色，但一旦资源循环建立起来，就能形成数量优势。

---

## 3.4 网柄菌

### 角色名

**网柄菌**

可选游戏化名称：

- 聚群变形菌
- 孢子塔菌群
- 群体变形菌

### 生物特点

网柄菌平时可以像单个变形虫一样活动。当食物不足时，多个个体会聚集起来，形成类似多细胞结构的群体，并最终产生孢子。

在游戏中，网柄菌代表“群体协作与牺牲分工路线”。

### 职业定位

**组织者 / 召唤师**

适合喜欢控制群体、调度单位、进行战略迁移的玩家。它的核心不是单体强度，而是群体组织能力。

### 进化路线

```text
单体变形细胞
  ↓
趋化聚集体
  ↓
迁移群体
  ↓
孢子塔
  ↓
群体分工生命体
```

### 核心技能

| 技能名 | 技能效果 |
|---|---|
| 趋化信号 | 召集附近同类向指定区域聚集 |
| 群体迁移 | 多个个体组成移动群体，穿越不利区域 |
| 孢子塔 | 牺牲部分个体，制造高处孢子结构，扩大传播范围 |
| 分工进化 | 将族群分为防御型、移动型、繁殖型单位 |
| 饥荒转化 | 食物不足时自动进入聚集与孢子传播路线 |

### 玩法总结

网柄菌是最有“进化感”的角色之一。它能从单细胞玩法过渡到类多细胞玩法。玩家需要决定哪些个体牺牲、哪些个体变成孢子、什么时候迁移到新区域。

---

## 3.5 眼虫

### 角色名

**眼虫**

### 生物特点

眼虫具有鞭毛，可以主动移动。它既可以利用光照获取能量，也可以在某些情况下摄取外界有机物，因此具有比较灵活的生存方式。

在游戏中，眼虫代表“探索与机动路线”。

### 职业定位

**斥候 / 游击者**

适合喜欢探索地图、寻找资源、快速转移的玩家。眼虫不适合长期固定防守，但非常适合侦查、抢资源和规避危险。

### 进化路线

```text
原始鞭毛细胞
  ↓
趋光眼虫
  ↓
双能源细胞
  ↓
高速探索体
  ↓
适应型游击者
```

### 核心技能

| 技能名 | 技能效果 |
|---|---|
| 鞭毛推进 | 提升移动速度 |
| 眼点感光 | 感知光源、阴影和危险区域 |
| 混合营养 | 有光时进行光合，黑暗时消耗有机物生存 |
| 形变穿隙 | 穿过狭窄地形或复杂水域 |
| 快速撤离 | 遭遇强敌时短时间提升逃脱能力 |

### 玩法总结

眼虫适合做探索型角色。它的优势在于灵活，不依赖单一资源。玩家可以用它快速侦查未知区域，寻找适合后续族群扩张的地点。

---

## 3.6 黏细菌

### 角色名

**黏细菌**

可选游戏化名称：

- 黏菌猎群
- 滑行猎手
- 黏膜军团

### 生物特点

黏细菌擅长群体行动，可以集体滑行，并通过释放分解酶捕食其他微生物。当环境恶劣时，它们也可以形成子实体和孢子结构。

在游戏中，黏细菌代表“群体掠食路线”。

### 职业定位

**猎手 / 军团**

适合喜欢进攻、围猎、压制敌人的玩家。黏细菌单体并不一定强，但成群行动时威胁很高。

### 进化路线

```text
滑行细菌
  ↓
群体猎手
  ↓
生物膜军团
  ↓
子实体孢子群
  ↓
掠食型微生物军团
```

### 核心技能

| 技能名 | 技能效果 |
|---|---|
| 群体滑行 | 多个单位靠近时移动速度和行动效率提升 |
| 酶解猎物 | 分解敌方微生物，转化为营养 |
| 围猎信号 | 标记目标，使附近同类集中攻击 |
| 生物膜护盾 | 群体形成保护层，提升整体防御 |
| 子实体 | 营养不足时形成孢子结构，保存族群核心 |

### 玩法总结

黏细菌适合作为后期角色，或者先作为敌对阵营出现。它能提供明显的战斗玩法，让游戏不只停留在生存和资源经营层面。

# 4. 首版角色推荐

如果第一版开发资源有限，建议先做 4 个角色：

| 推荐顺序 | 角色 | 原因 |
|---|---|---|
| 1 | 芽孢杆菌 | 最贴合“孢子进化”主题，适合新手 |
| 2 | 蓝细菌 | 提供光照、生态改造、地图扩张玩法 |
| 3 | 酵母菌 | 提供资源转化和快速繁殖玩法 |
| 4 | 网柄菌 | 提供群体协作、分工、孢子塔等特色机制 |

后续版本可以加入：

| 后续角色 | 加入价值 |
|---|---|
| 眼虫 | 增加探索、移动、地图侦查玩法 |
| 黏细菌 | 增加战斗、围猎、敌对微生物玩法 |

# 5. 职业体系总结

| 职业 | 对应角色 | 核心玩法 |
|---|---|---|
| 生存者 | 芽孢杆菌 | 抗性、休眠、复苏 |
| 生态改造者 | 蓝细菌 | 光合、扩张、改变环境 |
| 工程师 | 酵母菌 | 发酵、资源转化、快速繁殖 |
| 组织者 | 网柄菌 | 聚集、分工、牺牲、传播 |
| 斥候 | 眼虫 | 探索、机动、趋光 |
| 猎手 | 黏细菌 | 围猎、群体战斗、捕食 |

# 6. 基础玩法循环

```text
出生
  ↓
寻找资源
  ↓
繁殖扩张
  ↓
遭遇环境压力
  ↓
选择进化方向
  ↓
获得新技能
  ↓
适应新生态位
  ↓
传播孢子或建立群落
```

不同角色在这个循环中的重点不同：

| 角色 | 循环重点 |
|---|---|
| 芽孢杆菌 | 遭遇压力后进入休眠，再等待复苏 |
| 蓝细菌 | 抢占光照区域，逐步改造环境 |
| 酵母菌 | 获取糖分，快速繁殖并生产代谢物 |
| 网柄菌 | 饥荒时聚集，形成孢子塔迁移 |
| 眼虫 | 主动探索地图，寻找最佳生态位 |
| 黏细菌 | 围猎其他微生物，把敌人转化为资源 |

# 7. 孢子系统设计

“孢子”可以作为游戏的统一核心系统，但不同角色的孢子机制应有差异。

| 角色 | 孢子机制 | 游戏作用 |
|---|---|---|
| 芽孢杆菌 | 保命型芽孢 | 在恶劣环境中休眠保存自身 |
| 网柄菌 | 传播型孢子 | 借助孢子塔扩散到新区域 |
| 黏细菌 | 群体保存型孢子 | 在饥荒或失败时保留族群核心 |
| 酵母菌 | 休眠孢子 / 繁殖种子 | 在资源周期变化中保存种群 |
| 蓝细菌 | 耐受细胞 / 休眠细胞 | 应对黑暗、干旱或营养不足 |
| 眼虫 | 包囊形态 | 临时防御和等待环境恢复 |

# 8. 设计建议

## 8.1 第一版控制复杂度

第一版不要把所有生物都做复杂。建议先做 4 个核心角色，每个角色只做 3–5 个关键技能。

## 8.2 每个角色必须有缺点

| 角色 | 主要缺点 |
|---|---|
| 芽孢杆菌 | 繁殖慢，主动进攻弱 |
| 蓝细菌 | 依赖光照，怕黑暗和遮挡 |
| 酵母菌 | 依赖糖分，资源贫瘠时弱 |
| 网柄菌 | 需要数量基础，前期单体弱 |
| 眼虫 | 单体脆弱，不适合正面战斗 |
| 黏细菌 | 依赖群体，分散时效率低 |

## 8.3 进化不只是数值增强

每次进化最好改变玩法，而不是只增加攻击、防御、速度。

示例：

- 单体 → 群体
- 被动生存 → 主动扩张
- 资源采集 → 环境改造
- 普通繁殖 → 孢子传播
- 个体行动 → 群体分工

# 9. 最终推荐组合

## 9.1 首版 4 角色

```text
芽孢杆菌：生存防御
蓝细菌：光合扩张
酵母菌：资源转化
网柄菌：群体协作
```

## 9.2 完整 6 角色

```text
芽孢杆菌：生存者
蓝细菌：生态改造者
酵母菌：工程师
网柄菌：组织者
眼虫：斥候
黏细菌：猎手
```

这个组合可以覆盖：

- 生存
- 生产
- 探索
- 战斗
- 扩张
- 协作

适合作为《孢子进化》游戏的第一批核心角色体系。
