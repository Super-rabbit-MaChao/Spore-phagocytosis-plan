# 《孢子进化》探索、撤离与失败规则设定

## 一、文档定位

本文档用于记录《孢子进化》的地图目标设计、探索目的、孢子化撤离机制和失败条件。

本次设定明确：

```text
地图没有固定通关条件。
角色进入地图的主要目的，是获取资源、承受环境压力并完成进化。
玩家可以随时尝试通过孢子化退出地图。
```

---

# 二、地图目标定位

## 1. 不设置传统通关条件

本游戏不采用传统关卡式“打完目标就通关”的结构。

地图不是一次性关卡，而是一个可反复进入的生态环境。

玩家进入地图的主要目的包括：

| 目的 | 说明 |
|---|---|
| 获取资源 | 收集能量、水分、营养、糖分、矿物质等 |
| 承受压力 | 经历干旱、毒素、酸碱、高温、竞争等环境压力 |
| 触发进化 | 在地图中满足进化条件 |
| 扩张菌群 | 通过蔓延占领更多格子 |
| 制造孢子 | 为撤离、传播和继承做准备 |
| 探索新区域 | 揭示更多未知格，发现稀有资源或特殊事件 |
| 进入新环境 | 通过传播事件进入其他地图 |

---

## 2. 地图的真正价值

```text
地图 = 进化场
```

培养皿提供安全恢复，但不能进化。

地图虽然危险，但能提供：

- 进化条件；
- 稀有资源；
- 环境适应压力；
- 孢子传播机会；
- 新地图入口；
- 高风险高收益事件。

---

# 三、探索动机

由于没有固定通关条件，必须让玩家有主动探索动力。

## 1. 主要探索动力

| 动力 | 说明 |
|---|---|
| 能量需求 | 孢子化撤离需要大量能量，玩家必须收集能量 |
| 进化需求 | 进化必须在地图中触发，培养皿无法完成 |
| 资源需求 | 培养皿恢复和投喂需要地图资源 |
| 稀有资源 | 高级进化材料只在特定地图出现 |
| 传播机会 | 某些格子可以把孢子带到新地图 |
| 风险收益 | 探索越深，奖励越高，但失败风险越高 |

---

## 2. 能量与撤离的关系

核心规则：

```text
孢子化退出地图需要消耗大量能量。
```

因此玩家不能刚进入地图就无成本退出。

玩家需要在地图中：

```text
翻格 → 找资源 → 采集能量 → 承受风险 → 选择合适时机孢子化撤离
```

这会形成基本策略：

| 状态 | 玩家选择 |
|---|---|
| 能量不足 | 继续探索，寻找能量 |
| 能量刚好够撤离 | 可以保守撤离 |
| 能量充足 | 可以继续深入探索 |
| 资源多但危险高 | 考虑及时孢子化撤离 |
| 快失败但能量不足 | 可能无法安全撤离 |

---

# 四、孢子化撤离机制

## 1. 孢子化撤离定义

孢子化撤离是玩家主动结束当前地图探索的主要方式。

玩家消耗行动点和大量能量，将核心菌落或部分族群转化为孢子，然后带回培养皿或进入传播结算。

---

## 2. 孢子化撤离条件

| 条件 | 说明 |
|---|---|
| 有剩余行动点 | 孢子化需要消耗 1 点行动点 |
| 能量足以支付消耗 | 至少能支付 `max(1, ceil(当前能量 × 0.1))` |
| 核心菌落未死亡 | 核心菌落死亡后不能主动撤离 |
| 族群未归零 | 族群归零已失败，无法撤离 |
| 未被特定状态禁止 | 例如严重中毒、被冻结、被免疫吞噬等 |
| 当前格允许撤离 | 第一版可允许任意格撤离；传播格提供加成 |

---

## 3. 孢子化撤离消耗

已确认规则：

```text
消耗 1 行动点 + 按体量扣除 10% 能量（最低 1 点）。
```

### 计算公式

| 项目 | 规则 |
|---|---|
| 体量定义 | 执行孢子化瞬间的当前能量值 |
| 能量消耗 | `max(1, ceil(当前能量 × 0.1))` |
| 行动点 | 固定消耗 1 点 |
| 族群 | 第一版不因孢子化额外强制扣族群；撤离成功后按结算转化为孢子库存 |
| 能量不足 | 当前能量 < 1，或不足以支付最低 1 点消耗时，无法主动孢子化撤离 |

示例：

| 当前能量 | 消耗 |
|---:|---:|
| 1 ~ 10 | 1 |
| 11 ~ 20 | 2 |
| 50 | 5 |
| 100 | 10 |

体量越大，撤离成本越高，从而限制“囤积后零成本退出”。

## 4. 孢子化撤离收益

| 收益 | 说明 |
|---|---|
| 带回资源 | 带回当前携带资源的全部或高比例（第一版建议 100% 携带库存） |
| 固化进化 | 本局获得的临时进化在成功撤离后永久保留 |
| 保留核心菌种 | 角色返回培养皿 |
| 产生孢子库存 | 按撤离时族群规模的一定比例记入该角色孢子（第一版建议 20%，至少 1） |
| 解锁地图记录 | 记录本次探索发现过的资源、事件和进化条件 |
| 传播格加成 | 在传播格撤离时，提高传播成功率或额外图鉴/资源奖励 |

---

# 五、失败条件

虽然没有通关条件，但仍然有失败条件。

## 1. 核心失败条件

**主失败条件（已确认）：**

```text
族群数量归零 → 本次探索失败。
```

| 失败条件 | 说明 |
|---|---|
| 族群数量归零 | 主失败条件；种群崩溃，无法继续行动 |
| 核心菌落死亡 | 通常伴随族群归零或直接判定失败 |
| 能量耗尽且无法恢复 | 无法行动、无法孢子化；若维持消耗继续压低族群至 0，则失败 |
| 水分归零且无法恢复 | 细胞失活；若导致族群归零，则失败 |
| 严重环境清除 | 消毒、免疫吞噬等直接清除核心并导致族群归零 |

说明：第一版以「族群归零」作为统一失败落点。能量/水分归零本身先进入濒危，不立刻判负，但会快速导致族群崩溃。

## 2. 地图特有失败条件

| 地图 | 失败条件示例 |
|---|---|
| 土壤 | 干旱中水分长期不足，族群归零 |
| 淡水池塘 | 被水流冲离后核心死亡、族群归零 |
| 腐烂水果 | 腐败崩坏时仍未撤离，族群被清除 |
| 人体 | 被免疫系统彻底清除 |
| 污水管道 | 消毒事件清除核心菌落 |
| 极端环境 | 抗性不足，被极端环境杀死 |

---

# 六、失败后的结算

失败代表本次地图探索失败，不代表游戏整体结束。

## 1. 失败结算（第一版）

```text
失败后回到培养皿。
本局临时进化全部不保留。
本局未撤离的携带资源按低比例残留或不带回（第一版建议不带回）。
该角色保留培养皿中已分配库存与已永久进化。
族群按培养皿规则以真实时间缓慢恢复；可用已分配资源投喂加速。
```

| 项目 | 失败 | 成功孢子化撤离 |
|---|---|---|
| 临时进化 | 全部丢弃 | 全部固化为永久进化 |
| 携带资源 | 不带回 | 带回 |
| 角色存续 | 保留，回到培养皿 | 保留，回到培养皿 |
| 永久进化 | 不受影响 | 新增本局固化项 |
| 地图布局 | 下次进入重新生成 | 下次进入重新生成 |

## 2. 设计原则

```text
第一版失败惩罚以“丢失本局收益”为主，不以删号或毁培养皿为代价。
已永久解锁的进化与已分配到角色的库存不因单次失败回滚。
```

---

# 七、撤离与失败的策略关系

玩家每次探索都需要权衡：

```text
继续探索，可能获得更多资源和进化。
立即孢子化撤离，可以保住已有成果。
能量不足时无法撤离，所以需要提前准备。
```

## 1. 风险决策

| 情况 | 建议行为 |
|---|---|
| 能量充足，危险低 | 继续探索 |
| 能量充足，危险高 | 考虑撤离 |
| 能量不足，资源少 | 被迫冒险寻找资源 |
| 已触发进化 | 优先考虑安全撤离以固化进化 |
| 核心菌落濒死 | 尝试孢子化保命 |
| 地图事件即将爆发 | 判断是否撤离或进入孢子状态 |

---

# 八、地图没有通关条件后的替代目标

没有通关条件不代表没有目标。目标从“通关”变成“阶段收益”。

## 1. 单次探索目标

| 目标 | 示例 |
|---|---|
| 获取资源 | 带回 100 能量 |
| 完成进化 | 解锁一个新进化节点 |
| 制造孢子 | 生成 30 个孢子 |
| 探索地图 | 揭示 30 个格子 |
| 占领区域 | 占领 10 个格子 |
| 发现事件 | 找到一次特殊传播事件 |
| 生存挑战 | 熬过一次干旱、消毒或腐败事件 |

---

## 2. 长期目标

| 目标 | 示例 |
|---|---|
| 强化角色 | 通过分配资源与永久进化提升角色 |
| 解锁地图 | 通过传播进入新环境 |
| 完善进化树 | 解锁角色分支 |
| 收集图鉴 | 记录资源、敌人、事件、进化 |
| 培养多角色 | 建立多个微生物菌种 |
| 挑战高难度环境 | 进入人体、污水、极端环境 |

---

# 九、第一版规则摘要

```text
地图没有固定通关条件。
角色进入地图是为了获取资源和触发进化。
玩家可以随时尝试孢子化退出地图。
孢子化消耗 1 行动点 + 当前能量的 10%（最低 1 点）。
成功撤离后，本局临时进化永久保留；失败则丢弃本局进化。
失败主条件：族群数量归零。
地图每次进入重新生成；局内资源采后不再生。
```

---

# 十、进化固化规则（关联）

| 状态 | 规则 |
|---|---|
| 地图内进化 | 立即生效，但是临时进化 |
| 成功孢子化撤离 | 临时进化全部永久保留 |
| 探索失败 / 未撤离 | 临时进化全部失效 |
| 进化是否失败 | 不存在失败；只改变不同环境的资源消耗 |
